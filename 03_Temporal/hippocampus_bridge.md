# Hippocampus Bridge & Episodic Memory

Bridges real-time sensory experiences to long-term memory graph structures. Initialized as a blank-slate.

## Neural Signal Pathways
- Anchored to [[03_Temporal/README|Temporal Lobe Subsystem]]
- Consolidates incoming buffers from [[03_Temporal/sensory_buffer|Short-Term Sensory Buffer]]
- Triggers dynamic synaptic weight updates in [[02_Parietal/synaptic_matrix|Synaptic Matrix]]
- Structures episodic nodes linking into [[03_Temporal/semantic_graph|Semantic Memory Graph]]
- Provides experiential context during goal formulation in [[01_Frontal/goal_formulator|Goal Formulator]]
- Logs execution traces from [[04_Cerebellum/action_dispatcher|Action Dispatcher]]
